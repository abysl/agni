# Unleashed (UNL)

Provenance: the Unleashed set, every base print unl-001 to unl-219 in collector order, from the Riftcodex catalog dump of 2026-09-10; alternate art, overnumbered and signature prints resolve to the base name through base_name (the Ultimate print of Baron Nashor, unl-238-219, is one more overnumbered print and resolves the same way); text from Riftcodex by riftbound id, with the attached line of each Equipment appended from the card image (the catalog omits it, the might badge last as +N :rb_might:), the stray "ambush" the catalog appends to Gemhand Hunter dropped (the card prints no Ambush) and Ultrasoft Poro's token line read as the card prints it (two 1 :rb_might: Bird unit tokens, where the catalog has an energy icon for the 1)

Scripted: partial

A set file, not a deck: it carries no deck block and no coaching. Every card line reads byte for byte as it does in the deck files that share it. The set prints no runes and no token faces of its own; the engine spawns tokens by name. Partial because 20 cards stay stubs — CARD is the generic constructor of its kind with the pool name and the printed keywords — since their whole text is one mechanic the engine does not have yet (each names its seam and carries an ignored test of the behaviour it wants; the M12 table in wiki/design/rules-engine.md lists them); the other 199 run on scripts of their own, six of them vanillas whose printed keywords are the whole script, and the 27 cards shared with the deck files run on the deck files' scripts.
